# Python Programming Labs

A collection of **48 Python exercises** completed during the Cloud Programming course at WSB University (Computer Science – Cloud Computing).
The labs progress from the basics to functional programming patterns that are used later in cloud scripting and automation.

## Contents
| Folder | Topic | Examples |
|--------|-------|----------|
| [`01-setup`](01-setup) | Project setup | First Python project, running scripts |
| [`02-variables`](02-variables) | Variables & data types | Dynamic typing, mutability, `is` vs `==`, truthiness, safe conversion |
| [`03-conditionals`](03-conditionals) | Conditional logic | Shipping cost calculator, score-to-grade converter |
| [`04-mini-challenges`](04-mini-challenges) | Mini challenges | `match / case` (Python 3.10+) |
| [`05-lists`](05-lists) | Lists | Clean & normalize input, deduplicate, chunk, flatten, stats |
| [`06-loops`](06-loops) | Loops | `for` / `while` loops, FizzBuzz+ |
| [`07-dictionaries`](07-dictionaries) | Dictionaries | Safe dotted-path access, merge defaults, pick / omit keys, group by |
| [`08-lambdas-and-sorting`](08-lambdas-and-sorting) | Lambda functions | Sorting by key, closures, higher-order predicates |
| [`09-function-pipelines`](09-function-pipelines) | Functional programming | Higher-order functions, `pipe()` / function composition |

## How to run
Requires Python 3.10 or newer. Each file is a stand-alone script with its own test cases:
```bash
python 09-function-pipelines/S3_PIPE_01.py
```

## Skills
Python 3, data structures, control flow, functions, lambda expressions, higher-order functions, functional composition, writing self-testing scripts.
